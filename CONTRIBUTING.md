# Contributing

Issue reports and proposed improvements are welcome. Before submitting a change:

1. Create a focused branch from the default branch.
2. Add or update tests for behavioral changes.
3. Run the installation check and full test suite from `README.md`.
4. Avoid committing sample data unless it is synthetic, small, and clearly licensed.
5. Describe user-visible behavior and data-safety implications in the pull request.

By submitting a contribution, you confirm that you have the right to provide it and
grant the repository owner permission to use, modify, and distribute it as part of
this project. Contact the repository owner before contributing if you need different
terms.

## AI-assisted contributions

Disclose material use of coding assistants in the pull-request description. When a
commit was prepared with OpenAI Codex, the following optional commit-message footer
records that assistance without claiming a GitHub co-author identity:

```text
Assisted-by: OpenAI Codex
```

The contributor remains responsible for reviewing, testing, and approving all
AI-assisted changes before submission.
